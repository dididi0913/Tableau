# 1️⃣ 🧠 핵심 개념 카드

이번 주부터는 개념을 표로만 정리하지 않고, **개념 카드** 형태로 정리합니다. 계산 관련 개념은 “언제 쓰는지”와 “주의할 점”을 함께 적어야 나중에 다시 보기 좋습니다. 필요하다고 생각하면 2개보다 더 많이 정리해도 좋습니다.

> 예시 개념: 계층, 집합, 결합집합, 계산된 필드, 행 수준 계산, 집계 계산, 테이블 계산, 퀵테이블 계산

## 개념 1. `계층`

**1. 이 개념을 한 문장으로 설명하면?**

```
뷰에서 데이터를 "Drill Down"해 값을 세부적으로 찾는 방법
```

**2. 언제 사용하나요?**

```
ex. 닐짜별 매출 볼 때, 오른쪽 버튼 누르면 분기별, 월별, 일별로 확인 가능
```

**3. 이번 실습에서 어떻게 확인했나요?**

```
"위치"필드 왼쪽에 계층으로 구분할 수 있는 아이콘이 있고
해당 필드는 지역, 국가, 시/도, 도시 필드들을 계층으로 묶음
```

**4. 헷갈린 점 또는 주의할 점은?**

```
계층을 만드려면 두 필드를 선택한 후 마우스 우클릭을 함
그 후 계층에서 계층 만들기 버튼 클릭!. 그리고 나머지 필드들을 계층으로 드래그. 
```

## 개념 2. `집계 계산`

**1. 이 개념을 한 문장으로 설명하면?**

```
현재 뷰에서 보이는 기준으로 계산하는 방식
```

**2. 언제 사용하나요?**

```
표시되는 계산 방식을 변경하고 싶을 때, 필드에 마우스 우클릭하고 "기본 속성"에 "집계"를 선택해 원하는 집계 선택 가능. 
```

**3. 이번 실습에서 어떻게 확인했나요?**

```
집계 계산식을 통해 계산된 필드 만들기. 태블로가 만들었던 필드에 마우스 우클릭하면 집계 변경 가능하지만, 직접 만든 필드를 클릭하면 계산 수단 옵션이 없다. 
```

**4. 헷갈린 점 또는 주의할 점은?**

```
사용자가 집계 계산된 필드를 만들면 해당 필드에 "집계"를 나타내고 마우스 우클릭으로 변경이 안됨
```
